📦 HOW TO BUILD THE APK

1. Open the repository on GitHub.
2. Select the Actions tab.
3. Open the Build RIVO APK workflow.
4. Run the workflow if necessary.
5. Wait until the build finishes successfully.
6. Open the completed workflow.
7. Download the "RIVO-debug-apk" artifact.
